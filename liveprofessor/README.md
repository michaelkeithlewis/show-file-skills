# liveprofessor: LiveProfessor 2 sessions

A Claude Code skill and Python scripts for LiveProfessor 2 session files (`.rack2`).
They dump a session, summarize its chains, plugins and routing, and generate a
pre-routed insert session from a JSON channel list: one chain per console channel,
hardware in to chain to hardware out, with plugin chains copied from a session you
already have.

## What is in the folder

- `SKILL.md`: the skill. Claude Code loads it when you ask about LiveProfessor.
- `scripts/vt.py`: JUCE binary ValueTree reader and writer (byte-exact round trip). Also a full dump CLI.
- `scripts/summary.py`: device, chains, plugins and routing in a few lines.
- `scripts/check_derive.py`: checks the rule the generator uses to rebuild the current state.
- `scripts/lp_generate.py`: base session + `channels.json` to a new session.
- `references/FORMAT.md`: format notes (ValueTree encoding, node map, routing, ids).
- `examples/channels.json`: a made-up 10-chain insert list.

## Requirements

- Python 3.8 or later. No other packages.
- LiveProfessor 2 and one session it saved, to use as the base. No sessions or plugins
  ship with this folder.

## Quick start

```
python3 scripts/summary.py "My Base.rack2"
python3 scripts/check_derive.py "My Base.rack2"
# edit examples/channels.json: chain names from your base, your channel list
python3 scripts/lp_generate.py "My Base.rack2" examples/channels.json "Demo.rack2"
python3 scripts/summary.py "Demo.rack2"
```

To install as a skill, copy this folder to `~/.claude/skills/liveprofessor-session/`.

## Status

- Proven: `vt.py` round-trips every sample byte for byte. The current-state rule in
  `check_derive.py` held on three real sessions. A session generated by the earlier
  version of `lp_generate.py` (48 insert chains over Dante, plugin chains copied from
  another show) opened in LiveProfessor 2 and worked.
- Not proven: the `DelayMode` meaning, sessions with MIDI routing beyond the defaults,
  and Windows-saved bases with device types other than ASIO.
- Verified for this release: `python3 -m py_compile` and `--help` on every script,
  `check_derive.py` on three private sessions (all match), and `lp_generate.py` with
  `examples/channels.json` (chain names mapped to a private base) followed by
  `summary.py`, `check_derive.py` and `vt.py` on the output. The private sessions are not included.
